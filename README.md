# DevFit IR Deck

중간발표용 IR 덱입니다.

- `irdeck_new.html`: 30장 발표 덱 (본편 26장 + 부록 4장)
- `deck_assets/`: 덱에서 사용하는 이미지와 로고
- `index.html`: GitHub Pages 진입점

## 구성

| 구간 | 슬라이드 |
|---|---|
| 도입 | 표지 · 팀 · 멘토 |
| 문제 | 문제제기 · 정보 비대칭 |
| 제품 | 제품 구조 · 솔루션 |
| 시장 | 시장 동향 · 시장 규모 · 경쟁사 · 비즈니스 모델 |
| 서비스 | 지원자용 · 기업용 |
| 기술 | 커밋 선별 · 분석 아키텍처 · LLM 운영 · 품질 측정 · 인프라 · 모델 선정 |
| 진행 | 개발 진행현황 · 계획(B2C/B2B) · 추진 일정 · 기획심의 반영 |
| 마무리 | 기대 효과 · 클로징 |
| 부록 | 피벗 의사결정 · 리스크와 대응 · 경쟁 전수조사 · 단위경제성 |

## 수치 근거

덱의 시장·가격·원가 수치는 **중간보고서(제출본)와 일치**시켰다. 보고서는 제출 후 수정이 불가하므로,
수치를 바꿀 때는 보고서 기준을 먼저 확인할 것.

- SOM 연 26.0억 원 = 520,278명 × 지원자 1인당 5,000원 (침투율 10%)
- ARPA 200,000원 · 총이익률 62% · LTV 309,600원 · CAC 103,200원
- 분석 1회 변동비 330원(레포 3개) / 1,404원(20개 상한) / 재분석 0원

## 조작

- 방향키·PageUp/Down·스페이스·휠: 슬라이드 이동
- `F`: 전체화면 · `Home`/`End`: 처음/끝
- 쪽번호는 `data-order` 정렬 순서대로 런타임에 자동 부여된다(표지 제외)
- PDF 변환: 브라우저 인쇄 → 용지 20in × 11.25in, 배경 그래픽 켜기
